# Анализ риска инвестиционного портфеля методом Монте-Карло

**Pet-проект для портфолио Data Scientist / Quantitative Finance**

[![Python](https://img.shields.io/badge/Python-3.9%2B-blue)](https://www.python.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

Образовательный end-to-end проект, который показывает, как использовать **симуляцию Монте-Карло** для количественной оценки неопределённости и риска многоактивного портфеля акций.

---

## Зачем этот проект?

Метод Монте-Карло — один из самых практичных инструментов в управлении рисками.  
Вместо одного «точечного прогноза» мы получаем **полное распределение** возможных исходов и можем ответить на вопросы:

- Какой Value-at-Risk (VaR) на уровне 95% / 99% на горизонте 1 года?
- Какой ожидаемый убыток в худших сценариях (CVaR / Expected Shortfall)?
- Какова вероятность потерять деньги / заработать +20% / удвоить капитал?
- Как корреляции между активами влияют на риск портфеля?

Проект сделан чистым, хорошо документированным и готовым к публикации на GitHub — подходит для портфолио начинающего / junior Data Scientist.

## Методология (кратко)

1. **Данные** — скорректированные цены закрытия AAPL, MSFT, GOOGL, AMZN, META, NFLX с 2020 года.
2. **Доходности** — дневные simple returns → вектор средних \(\mu\) и ковариационная матрица \(\Sigma\).
3. **Симуляция** — 10 000 траекторий равновесного портфеля на 252 торговых дня.  
   Коррелированные шоки генерируются через разложение Холецкого матрицы \(\Sigma\) (дискретная аппроксимация многомерного геометрического броуновского движения).
4. **Метрики риска**
   - Value-at-Risk (VaR) 95% / 99%
   - Conditional VaR / Expected Shortfall
   - Вероятность убытка, роста на +20%, удвоения капитала
   - Полное распределение конечной стоимости портфеля

## Какие выводы вы получите

После запуска ноутбука вы увидите (цифры меняются при свежих данных):

- Ожидаемую и медианную конечную стоимость портфеля
- Наглядную визуализацию 5–95% доверительной полосы траекторий
- Конкретные значения VaR и CVaR как в долларах, так и в % от капитала
- Вероятностные утверждения, которые легко объяснять бизнесу и стейкхолдерам

## Возможные расширения (хорошо смотрятся на собеседованиях)

- Заменить равные веса на mean-variance или risk-parity оптимизацию
- Непараметрический Монте-Карло (бутстрап исторических доходностей)
- Модели волатильности GARCH / EWMA или regime-switching
- Анализ на нескольких горизонтах + бэктестинг VaR
- Учёт транзакционных издержек и периодической ребалансировки
- Стресс-сценарии (например, принудительно повышенные корреляции)
